本目录保存从权威机构官网下载、并通过格式校验的原始资料。当前共 11 份文件，约 15.8 MB；其中 5 份 PDF 共 558 页，6 份为完整 HTML 页面。

| --- | --- | --- | --- |

每份资料的来源地址、文件摘要、许可状态、地区标签和入库限制见 `sources.json`。

## 重要限制

这些文件是“原始来源层”，不能直接全部放入向量库：

1. 先抽取正文，删除导航栏、页眉页脚、目录重复文本和图片说明。
2. 英文资料需翻译为中文，并由具备心理学背景的人员逐条复核；原文与译文要保留关联。
3. 美国 NIMH 材料中的 `988`、`911` 等联系方式必须标记为 `region=US`，不得作为中国用户的危机联系方式返回。
4. mhGAP 等临床资料只能用于安全规则和专业知识参考，禁止据此让模型自行诊断、开药或调整药量。
5. 自杀与自伤内容应独立建索引或设置更高安全优先级；生成回复时仍须经过风险识别和安全 Agent 审核。
6. 政府网页和许可状态为 `review_required` 的资料，在公开再分发或商业使用前需要再次核对授权范围。

## 建议的下一步处理

将清洗后的文档统一转换为 JSONL，每个知识片段至少包含：

```json
{
  "chunk_id": "唯一编号",
  "text": "清洗后的中文正文",
  "title": "资料标题",
  "source_id": "sources.json 中的 id",
  "source_url": "官方来源地址",
  "language": "zh-CN",
  "region": "GLOBAL",
  "topic": ["stress_management"],
  "risk_level": "normal",
  "allowed_usage": "user_education",
  "review_status": "human_approved",
  "effective_date": null
}
```

建议按 300～500 个中文字符切分，保留 50～100 字重叠；表格、步骤列表和危机处置流程应按语义整体切分，不能机械截断。
